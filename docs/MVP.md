# Android Private Beta Scope

## Goal

Prove that a user can meet someone interesting, follow them, continue through DMs, and return later.

## Included

1. Account and 18+ onboarding
2. Lightweight authenticated profiles
3. Follow, block, and report
4. Language/topic-based text Quick Chat
5. Persistent text DMs
6. Text posts, likes, and replies
7. Basic Clubs and one live-audio room format
8. Push notifications and core funnel analytics

## Deferred until the core loop works

- Quick Chat voice
- Images and voice notes
- Gifts, coins, and ads
- Recommendation algorithms
- Animated gifts and profile cosmetics
- Public launch and non-Android clients

## Success signals

- Match connection rate
- Conversation duration
- Follow after Quick Chat
- DM continuation after Quick Chat
- Day-one return
- Reports and blocks per conversation
